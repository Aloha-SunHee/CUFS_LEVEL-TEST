# CUFS 중국어학부 레벨테스트 웹앱

학번과 이름으로 접속해 100문항(듣기 50 + 읽기 50)을 풀고, 난이도별 정답률로 수준을 진단받는 웹앱입니다. 처음 접속하면 시험 1개(1회)만 보이고, 한 번 응시한 뒤에는 **지난 시험 다시보기 / 새로운 시험 도전** 두 탭이 나옵니다. 새로 도전하면 아직 보지 않은 다음 회차(2회, 3회…)가 출제되고, 결과는 지난 시험과 비교해 보여 줍니다.

## 구성 (8세트, 세트 간 겹치는 문항 없음)
| 영역 | 번호 | 유형 | 난이도 |
|---|---|---|---|
| 듣기 | 1~6 | 음절 발음 듣기 | 입문 |
| | 7~12 | 성모·운모 변별 | 입문 |
| | 13~15 | 기초 문장 O/X | 초급 (HSK 1~2) |
| | 16~20 | 기초 회화 즉답 | 초급 |
| | 21~25 | 짧은 대화 | 초급 |
| | 26~33 | 단문 내용 일치 O/X | 중급 (HSK 3~4) |
| | 34~40 | 대화 이해 (3지선다) | 중급 |
| | 41~50 | 긴 담화 1개당 2문항 × 5 | **고급 (HSK 5~6)** |
| 읽기 | 1~5 | 한자 표기 O/X | 입문 |
| | 6~10 | 어휘 뜻 | 초급 |
| | 11~15 | 병음·성조 | 입문 |
| | 16~20 | 회화 응답 | 초급 |
| | 21~25 | 문장 연결 (보기 은행) | 중급 |
| | 26~30 | 어휘 채우기 (보기 은행) | 중급 |
| | 31~35 | 단문 독해 | 중급 |
| | 36~40 | 어휘 채우기 (보기 은행) | **고급** |
| | 41~44 | 단락 독해 | 중급 |
| | 45~50 | 장문 1개당 2문항 × 3 | **고급** |

세트마다 입문 22 · 초급 23 · 중급 34 · 고급 21문항입니다. 권장 시간은 듣기 30분, 읽기 40분입니다.

## 진단 방식
config.js의 `DIAGNOSIS_TIERS`에서 위에서부터 차례로 보고, 조건(난이도별 정답률)을 모두 만족하는 첫 등급으로 진단합니다.

| 등급 | 조건 |
|---|---|
| 5단계 (HSK 5~6) | 고급 60% 이상 + 중급 75% 이상 |
| 4단계 (HSK 4~5) | 고급 35% 이상 + 중급 65% 이상 |
| 3단계 (HSK 3~4) | 중급 45% 이상 + 초급 70% 이상 |
| 2단계 (HSK 1~2) | 초급 45% 이상 + 입문 60% 이상 |
| 1단계 (입문) | 그 외 |

진단 결과 아래에는 **추천 과목**이 함께 나옵니다. 과목 목록은 config.js의 `COURSES`에서 고치면 됩니다.
- 1·2단계: 초급 과목(중국어입문, 한자쓰기와 워드연습 등 7개)
- 3단계: 중급 과목(중국어 문법·작문Ⅰ/Ⅱ, 중급중국어회화 등 12개)
- 4단계: 중급 과목 + '다음 단계로 도전해 볼 과목'으로 고급 과목
- 5단계: 고급 과목(중국어로 읽는 중국문화, 취업인터뷰중국어 등 9개)

## 설치
1. 이 폴더 전체를 GitHub 새 저장소에 올리고, Settings → Pages에서 main 브랜치를 켭니다.
2. 새 구글시트에서 확장 프로그램 → Apps Script를 열고, `apps-script/Code.gs`를 붙여 넣은 뒤 `setup`을 한 번 실행합니다.
3. 프로젝트 설정 → 스크립트 속성에 다음을 넣습니다.
   - `TEACHER_PIN`: 교수자 비밀번호
   - `GEMINI_API_KEY`: AI 해설용 키 (선택)
4. 배포 → 새 배포 → 웹 앱(실행: 나 / 액세스: 모든 사용자)으로 배포하고, 나온 주소를 `config.js`의 `SCRIPT_URL`에 넣습니다.
5. 교수자 화면은 주소 끝에 `?teacher=1`을 붙여 엽니다. PIN 조회에 성공해야 시험 중 정답이 보입니다.

## 문항 고치기
- 문항 원본은 `tools/pools_base.py`(기존 초안 문항)와 `tools/pools_new_L.py`, `tools/pools_new_R.py`(2026-11 추가 문항)입니다. 새 문항은 보기를 **정답이 첫 번째**가 되게 씁니다.
- 고친 뒤에는 차례로 실행합니다.
  ```
  python3 tools/build_sets.py               # data/lt1~8.js 다시 만들기
  node tools/check_sets.js                  # 형식·정답·세트 간 중복 검사
  node tools/export_lt_jobs.js > lt_jobs.json.new && mv lt_jobs.json.new lt_jobs.json
  python3 tools/make_audio.py lt_jobs.json audio   # 바뀐 듣기 음성만 다시 생성 (Kokoro 모델 필요)
  ```
- 세트 id(lt1~lt8)와 문항 번호는 운영 중에 바꾸지 마세요. 바꾸면 이전 기록과 연결이 끊깁니다.
